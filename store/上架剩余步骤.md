```
Test instructions:
- No account or sign-in is required. The extension makes no network requests.
- After installing, open any page that contains an HTML5 video (for example a news site, Bilibili, YouTube). A small floating button appears in the top-right corner of the page showing the current speed (e.g. 1x).

- Language: the UI is Simplified Chinese; all logic is local, no data collection, no remote code.
```

## 说明：为什么自动化在这几步失败

Partner Center 的上传组件是 shadow DOM 自定义元素：合成的 `input.files` + change 事件在「首次上传程序包」能用，但在「替换程序包」和「截图/磁贴上传」上会静默假死或串槽（已实测：合成 File ×3、drop 事件、原生 `DOM.setFileInputFiles`、重启动浏览器、重新登录均无效）。**唯一一次成功是 CDP 原生拖放事件 `Input.dispatchDragEvent`**（zip 替换就是这么传上去的）。手动拖文件是最稳的。
