# Edge Add-ons 商店文案 · 中文（zh-CN）

## 名称
视频速度控制（页面悬浮）

## 简介（短描述）
在网页内部显示悬浮的速度按钮，点一下就能调视频播放速度；档位可自定义、按网站记忆，装在电脑上的「应用窗口」里同样能用。

## 详细描述

**和只躺在浏览器工具栏里的同类扩展不同：这个按钮画在页面上**，所以用 Edge「安装为应用」打开的窗口（B站 / 微博 / 小红书 / 油管等）里也能直接调速，不用切回浏览器。

**核心功能**
- 页面内悬浮按钮：默认贴在右上角，显示当前速度，点一下弹出菜单选档位
- 速度档位可自定义：0.1×–10×，最多 12 个；−/+ 微调、滑杆细调（滑杆下方实时显示当前值）
- 按网站记住速度：B站 1.5×、油管 2× 互不干扰（1× 是默认值，不会产生记录）
- **不与网站播放器打架**：你在网站自带播放器上手动调速时，扩展会读取并记住它，不会抢回；只有播放器刚换到新视频时才会把你设定的速度重新套用一遍
- 拖动定位：按住 Ctrl 再拖动按钮即可移动，位置自动记住（按窗口百分比存，窗口缩放不跑丢）
- 按钮外观：16 款样式（纯色 / 渐变 / 玻璃 / 发光呼吸）、尺寸 60%–500%、圆角可调、鼠标悬停与移开的不透明度分别可调（弹出菜单始终 100% 不透明，保证看得清）
- 全屏播放时按钮仍可用（自动搬进全屏播放器内部）；也可以在设置里改成**全屏时自动隐藏按钮**（播放器全屏 / 网站「网页全屏」（如 B站）/ 浏览器 F11 全屏都会隐藏，退出立即恢复）
- 快捷键：Ctrl+Shift+> 加快 / Ctrl+Shift+< 减慢 / Ctrl+Shift+0 重置
- 显示范围可控：只在有视频的页面显示 / 所有页面显示；可把指定网站加入排除清单
- 设置可导出导入（换电脑前备份）

**不适用的情况（浏览器安全限制，任何扩展都一样）**
- `edge://` 系统页、扩展商店页、Edge 内置 PDF 阅读器
- 不是由 Edge 打开的「应用」（例如抖音 PC 客户端这类独立程序）——它们不是浏览器渲染的页面

## 隐私
不收集任何数据。扩展只在本地使用 `chrome.storage.local` 保存你的设置（速度档位、按钮位置、样式、按网站记录等），不联网、不上传、不注入远程代码。
