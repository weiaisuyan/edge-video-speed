# 视频速度控制（页面悬浮）

在**网页内部**显示一个悬浮的速度按钮，点一下就能调视频播放速度。
和只躺在浏览器工具栏里的同类扩展不同：这个按钮画在页面上，所以**用 Edge「安装为应用」的窗口（B站 / 微博 / 小红书 / YouTube 等）里同样能直接调速**，不用切回浏览器。

## 安装（3 步）

1. 打开 `edge://extensions`
2. 打开左下角／右下角的 **开发人员模式**
3. 点 **加载解压缩的扩展**，选择本文件夹 `E:\程序\edge-video-speed`

装好后打开任意视频页面，页面右上角会出现一个写着当前速度的胶囊按钮。

> 开发者模式加载的扩展，Edge 偶尔会提示「请关闭开发者模式扩展」，选**保留**即可。

## 怎么用

| 操作 | 效果 |
|---|---|
| 点按钮 | 弹出菜单：档位网格 / −+ 微调 / 滑杆 / 重置 1× / 本网站不显示 / 设置 |
| 按住 **Ctrl** 再拖动按钮 | 移动按钮位置（松开自动记住，按窗口百分比存，挡住页面内容时用它挪开） |
| 在网站自带播放器上调速度 | 扩展**读取并记住**你调的值（按钮同步显示），绝不抢回、不会把你的调节改掉 |
| `Ctrl+Shift+>` | 加快一档 |
| `Ctrl+Shift+<` | 减慢一档 |
| `Ctrl+Shift+0` | 重置为 1× |

- 按网站记住速度：B站 1.5×、油管 2×，互不干扰。
- **和网站播放器不打架**：你在网页自带播放器（油管/B站的控制条）上手动调速时，扩展读取并记住它，不会抢回；只有在「播放器刚换到新视频」那一瞬间站点把速度重置为默认值时，扩展才会把你选的速度重新套用一遍（设置里可关）。
- **全屏看视频**：设置里「全屏播放时仍然显示按钮」默认开着——按钮会搬进全屏播放器内部（播放器容器是 `<video>` 本身的站点，则用浮层显示在全屏画面上），全屏里照样能调速。**把它关掉**，以下三种全屏都会自动把按钮藏起来（退出立刻恢复）：
  - 播放器的全屏按钮（原生全屏）
  - 网站自己的「网页全屏」（例如 B站，靠 CSS 铺满窗口，比如窗口比例和视频不一致、上下留黑边的情况）
  - 浏览器窗口全屏（F11 / Edge「全屏」，此时视频要占住大半个视口）
- 闲置 3 秒后按钮变淡（鼠标移上去立刻恢复）——「鼠标悬停时不透明度」「鼠标移开后的不透明度」「延时」三项都能在设置里单独调，也可以整个关掉。

## 设置（右键扩展图标 → 选项，或菜单里的「设置」）

- **通用**：启用开关 / 显示范围（只在有视频的页面 ↔ 所有页面）/ 全屏播放时仍然显示按钮 / 跟随网站播放器的调速 / 新视频自动套用速度
- **速度档位**：菜单里的档位可增可删（0.1×–10×，最多 12 个）；默认速度（用滑杆调，数值实时显示）；按网站记忆开关；微调步长
- **按钮外观**：16 款样式（纯色 4 / 渐变 4 / 玻璃 4 / 发光呼吸 4）、尺寸、鼠标悬停时不透明度、鼠标移开后的不透明度与延时、是否显示数字
- **按钮位置**：模拟窗口里点击/拖动定位，或一键回右上角
- **键盘快捷键**：总开关
- **网站排除**：清单里的网站不显示按钮（`zhihu.com` 命中其全部子域）
- **各网站记住的速度**：查看 / 单条清除 / 全部清空
- **备份与恢复**：导出 / 导入 JSON（Edge 的扩展设置不随账号同步）

## 已知边界

- `edge://` 系统页、扩展商店页、Edge 内置 PDF 阅读器无法注入（浏览器安全限制，任何扩展都一样）。
- **不是 Edge 安装的「应用」**（例如抖音 PC 客户端、哔哩哔哩客户端这类独立程序）碰不到，它们不是浏览器渲染的页面。
- 内嵌在 iframe 里的第三方播放器：顶层页面按钮调的速度会同步过去；极少数跨域播放器若自带速度记忆，可能以它自己的记录为准。
- 站点若用原生播放器之外的方案（如某些 DRM 播放器）限制倍速，扩展无法绕过。
- 播放速度不变调（保留音高），Chromium 默认行为。
- 「全屏时隐藏」的判定边界（只在把设置关掉后生效）：原生全屏一定算；网页全屏按「播放器铺满视口」或「视频被铺满视口的定位容器包着」识别，所以**窗口只是最大化、页面里视频不大**时不会隐藏（这是有意的，避免误伤）。F11 全屏要求视频占住大半个视口。
- 「全屏播放时仍然显示按钮」开着、且全屏元素是 `<video>` 时，按钮改用浏览器顶层浮层（popover）绘制——需要 Edge 114+（2023 年后的版本都满足）。

## 文件结构

```
manifest.json     扩展清单（MV3）
shared.js         设置默认值 / 主题色 / 站点匹配（content + 扩展页共用）
content.js        页面注入：悬浮按钮 + 菜单 + 速度施加引擎 + 全屏判定
background.js     后台服务（打开设置页的官方通道）
options.html/css/js   设置页
popup.html/css/js     点工具栏图标的快捷面板
_locales/         中英文案（zh_CN / en）
icons/            16 / 32 / 48 / 128
tools/make_icons.py   图标生成脚本（Pillow）
tests/            自动化探针（真实 Edge + CDP，见 tests/ 说明）
```
